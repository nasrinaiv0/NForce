## Scope

Reviewed caller evidence, NOT server-derived attendance totals; cannot post, consume benefits, disburse or replace weekly posting. Full pay-cycle engine and authoritative coverage/corrections remain gated. Statutory arithmetic: 13th-month pay, maternity differential, SIL, solo parent, paternity, VAWC, special women, separation and retirement. Existing authenticated private maker-checker evidence feeds server calculation; quote only, no employee entitlement inference, consumption or actual settlement. Evidence revisions, entitlement history, leave/benefit posting and special cases outstanding. P0.9 internal government reports and remittance remain, no official forms or submission. Live organization monetary summary is read-only, time-limited review access, exact cents, current permission, no fallback; rejects incomplete posting and adjustments. Original accruals only, not final settlement. No public write API.
